# FoodBot - Intelligent Recipe Recommendation Chatbot

## Project Description
FoodBot is a web-based chatbot that recommends food recipes
based on ingredients entered by users.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Machine Learning
- TF-IDF
- Logistic Regression
- SQLite
- Google Colab
- Ngrok

## Features
- Ingredient-based recipe recommendations
- Recipe search
- Vegetarian and non-vegetarian filters
- Cooking instructions
- Chat history storage

## Machine Learning
TF-IDF converts text into numerical features.
Logistic Regression predicts the user's query intent.

## Database
SQLite stores recipe details and chat history.

## How to Run
1. Install the libraries using requirements.txt.
2. Run app.py.
3. Open the Flask application through Ngrok.
