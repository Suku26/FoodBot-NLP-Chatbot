# 🍲 FoodBot – Intelligent Food Recipe Recommendation Chatbot

### An NLP and Machine Learning Based Mini Project

## 📌 About the Project

FoodBot is a web-based recipe recommendation chatbot developed using Python, Natural Language Processing (NLP), Machine Learning and SQLite.

The main purpose of FoodBot is to help users decide what to cook using the ingredients available in their kitchen. Users can enter ingredients or ask recipe-related questions in natural language, and the chatbot suggests matching recipes from its database.

## ✨ Features

- Interactive chatbot interface
- Ingredient-based recipe recommendations
- Recipe search by name
- Vegetarian and non-vegetarian recipe categories
- Cooking instructions and recipe details
- SQLite database integration
- Chat history storage
- Machine Learning based intent classification

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend development |
| Flask | Web framework |
| HTML | Webpage structure |
| CSS | User interface styling |
| JavaScript | Chat interaction |
| Scikit-learn | Machine Learning |
| TF-IDF | Text feature extraction |
| Logistic Regression | Intent classification |
| SQLite | Database management |
| Google Colab | Development environment |
| Ngrok | Public access to local Flask server |

## 🧠 Machine Learning Method

FoodBot uses TF-IDF to convert text messages into numerical features and Logistic Regression to identify the intent of a user's query.

Recipe recommendations are generated by matching ingredients in the user's message with ingredients stored in the SQLite database.

## ⚙️ Project Setup

1. Clone this repository.
2. Install the required packages using:

   `pip install -r requirements.txt`

3. Run the Python application.
4. Open the Flask application in your browser.

For Google Colab deployment, use Ngrok to expose the Flask server.
